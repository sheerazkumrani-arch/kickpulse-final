روزانہ آرٹیکل لکھنے کا آسان طریقہ (Pitchside Notes)

1) نیا آرٹیکل بنانا
   - فولڈر content میں فائل _TEMPLATE-match-preview.md کی کاپی بنائیں۔
   - نام بدلیں، مثلاً: inter-miami-vs-orlando-city-preview.md
     (صرف انگریزی چھوٹے حروف، نمبر اور ڈیش۔ خالی جگہ نہیں۔ یہی نام ویب ایڈریس بنے گا۔)
   - Notepad میں کھولیں۔ سب سے اوپر والا حصہ (دو --- کے بیچ) بھریں:
     title، description (120 سے 155 حروف)، date (2026-11-17 کی شکل میں)، category، image، imageAlt
   - لائن  draft: true  ہٹا دیں جب آرٹیکل تیار ہو۔ جب تک یہ لائن ہے، آرٹیکل ویب سائٹ پر نہیں آئے گا۔
     (آدھا لکھا ہوا آرٹیکل غلطی سے شائع ہونے سے بچنے کے لیے۔)

2) محفوظ کرنا
   - File > Save As > Encoding میں UTF-8 رکھیں۔ نام کے آخر میں .md ہو، .txt نہیں۔

3) تصویر لگانا
   - تصویر کو ps/static/images فولڈر میں رکھیں۔ نام انگریزی چھوٹے حروف میں، مثلاً inter-miami-vs-orlando.jpg
   - سائز 1600x900، اور 250 KB سے کم۔ squoosh.app سے چھوٹی کر لیں۔
   - سب سے اوپر بڑی تصویر کے لیے:
       image: /images/inter-miami-vs-orlando.jpg
       imageAlt: میدان میں داخل ہوتے کھلاڑی (انگریزی میں ایک چھوٹی لائن)
   - آرٹیکل کے بیچ میں تصویر، الگ لائن پر:
       ![تصویر کا بیان](/images/stadium.jpg "نیچے چھوٹی سی کیپشن")
   - نام کے بڑے چھوٹے حروف بالکل فائل جیسے ہوں۔ ورنہ آپ کے کمپیوٹر پر چلے گی مگر Vercel پر تصویر نہیں آئے گی۔
   - تصویر اپنی ہو یا Canva/Unsplash/Pexels/Pixabay کی۔ گوگل سے کاپی نہیں۔ کلب لوگو نہیں۔

4) اپلوڈ سے پہلے چیک
   - کمپیوٹر پر  node build.js  چلائیں، یا بس ڈیپلائے کریں اور Vercel کا بلڈ لاگ دیکھیں۔
   - یہ خود بتاتا ہے: description غلط، تاریخ غلط، تصویر نہ ملی، فائل کا نام غلط، آرٹیکل بہت چھوٹا۔
   - اگر بلڈ ناکام ہو تو Vercel پرانی ویب سائٹ ہی چلتی رہنے دیتا ہے۔ آپ کی لائیو سائٹ خراب نہیں ہوگی۔
   - ہر بار پہلے پرانی فائلوں کی بیک اپ کاپی رکھیں۔

5) Search Console کوڈ
   - build.js کے ساتھ verify.txt نام کی فائل بنائیں اور اس میں صرف content="..." کی ویلیو لکھیں۔
   - اس کے بعد build.js بدلنے پر یہ کوڈ دوبارہ نہیں لکھنا پڑے گا۔

6) روزانہ کا معمول (15 منٹ کا کام نہیں، پہلے ہفتے کے بعد آسان ہو جاتا ہے)
   - ایک مین کی ورڈ: "Team A vs Team B preview"۔ وہ ٹائٹل، پہلے پیراگراف اور ایک ہیڈنگ میں آئے۔
   - باقی کی ورڈز: predicted lineup، team news، injury news، where to watch۔ قدرتی جملوں میں۔
   - آرٹیکل کم از کم 500 الفاظ کا، اپنے الفاظ میں۔ اعداد و شمار اور خبریں سرکاری کلب یا لیگ سے لیں اور ذریعہ لکھیں۔
   - بیٹنگ کے الفاظ (over 2.5، correct score) استعمال نہ کریں۔
